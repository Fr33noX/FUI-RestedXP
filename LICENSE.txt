2. ATTRIBUTION — LiteTweaks (Jo)

The guide window reskin engine (Reskin.lua: the Frameless / Timeline /
Compact / Zygor-style / 8-Bit layouts, the navigation arrows and their
textures) is adapted from the RestedXP module of **LiteTweaks 1.46**, by
**Jo**. The chevron / card / classic / zygor textures in Textures/ come from
the same distribution.

The original distribution carried no explicit license. **The author, Jo, has
given explicit permission for this adaptation and its publication** (private
message, October 2026); his rights in his original work remain his. This
attribution is kept as thanks, and his interoperability request is honored:
FUI-RestedXP warns the user when LiteTweaks' RestedXP reskin is running
alongside (the two engines would otherwise fight over the same window). Any
further request from the original author will be honored promptly — contact:
the FUI-RestedXP CurseForge page.


3. DERIVED ASSETS — RestedXP Guides (RXP)
----------------------------------------------------------------

Textures/rxp-arrow-v2.png is a tintable rebuild (white outline, alpha
preserved, rescaled) of the v2 navigation arrow from RXPGuides' Blue theme;
the original artwork belongs to the RestedXP team. It exists here only to
color RestedXP's own guide window (when the "Fr33noX-UI" theme is selected
in RXP). No other RXPGuides file is included: the integration goes through
RXP's public interfaces only (RegisterTheme, ImportCustomThemes,
RXPGuides_Themes, settings profile).
